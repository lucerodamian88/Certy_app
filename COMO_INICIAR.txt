# INSTRUCCIONES PARA INICIAR EL AUDITOR CERTY

## PASO 1: Configura tu API Key de Gemini

1. Ve a: https://aistudio.google.com/app/apikey
2. Crea una nueva API key (es gratis)
3. Copia la API key

4. Ejecuta este comando en PowerShell (reemplaza TU_API_KEY con la que copiaste):

   $env:GEMINI_API_KEY="TU_API_KEY_AQUI"

   Ejemplo:
   $env:GEMINI_API_KEY="AIzaSyC1234567890abcdefghijklmnopqrstuv"

## PASO 2: Inicia el servidor

Una vez configurada la API key, ejecuta:

   python auditor_server.py

O simplemente:

   .\start_auditor.bat

Deberías ver:
   ✓ API Key configurada
   🚀 Servidor Auditor Certy iniciado en http://localhost:5000

## PASO 3: Usa la interfaz

Abre auditor.html en tu navegador y sube un PDF.

---

NOTA IMPORTANTE: La API key se configura solo para esta sesión de PowerShell.
Si cierras la terminal, tendrás que configurarla nuevamente.

Para hacerla permanente, usa:
   setx GEMINI_API_KEY "TU_API_KEY_AQUI"
(Necesitarás abrir una nueva terminal después de esto)
